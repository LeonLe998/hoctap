## Brand & Style

This design system is tailored for an intensive 12-week Career Transition and Learning Management platform bridging Human Resources Management (HCNS), Chinese (HSK), and English (TOEIC). The visual tone conveys executive rigor, structured discipline, and academic prestige. It rejects distracting gamification in favor of an authoritative, high-efficiency editorial workspace engineered for working professionals.

### Design Movement: Modern Corporate Minimalist
The aesthetic blends precision enterprise SaaS with editorial typography and tactile surface hierarchies:
- **Structural Integrity:** Razor-thin boundaries (`#E2E8F0`), high-contrast typographic balance, and deliberate white space that prevents cognitive fatigue during multi-hour study sessions.
- **Tonal Color Coding:** Distinct domain colors demarcate the three pillar subjects instantly across tracking tables, calendars, and performance analytics:
  - **HCNS (HR Administration):** Sapphire/Royal Indigo (`#2563EB`) — institutional trust, legal precision, operational competence.
  - **Chinese HSK:** Warm Ochre Amber (`#D97706`) — cultural depth, dedicated endurance, structural vocabulary mastery.
  - **English TOEIC:** Precision Emerald (`#059669`) — international communication, pragmatic progress, growth metrics.
- **Executive Clarity:** Crisp surface-on-slate contrasts give priority to time tracking, progress bars, schedule compliance, and audit-grade progress reporting.

## Typography

**Be Vietnam Pro** is used universally across all levels. It provides native, nuanced rendering for Vietnamese diacritics without accent clipping or baseline shifts, while its grotesque letterforms maintain razor-sharp technical precision in tabular study sheets and executive KPI summaries.

### Typography Guidelines
- **Diacritics Preservation:** Line heights must never fall below `1.35x` the font size to ensure marks such as dấu hỏi, ngã, and nặng stay legible and distinct from upper-level table borders.
- **Numbers & Metrics:** Quantitative representations (hours studied, days remaining, vocabulary counts, test scores) use tabular numbers (`font-variant-numeric: tabular-nums`) with semi-bold weights for scanability.
- **Case Rules:** Status pills and table column headers utilize sentence case or controlled uppercase with loose tracking (`letterSpacing: 0.04em`) to establish visual order.

## Layout & Spacing

The system deploys a modular 12-column desktop-first grid built to support data density without clutter.

### Layout Geometry
- **Primary Shell:** Fixed left persistent rail / navigation (`260px` expanded, `72px` collapsed) anchored in `#0F172A`.
- **Main Canvas:** Dynamic fluid area conforming to a max-width of `1600px` for ultra-wide displays with centered alignment.
- **12-Week Roadmap Grid:** Structured in multiples of 3 (quarters) and 12 (sprint milestones), allowing clean 3-column, 4-column, or weekly gantt projections.
- **Spacing Rhythm:** Standard 4px baseline unit. Primary component padding relies on `space-md` (`12px`) and `space-lg` (`20px`) to prevent visual crowding in dense tables and card groups.

### Breakpoints
- **Mobile (< 768px):** Single column stack, horizontal scrolling tables with sticky first columns, bottom bar navigation.
- **Tablet (768px - 1024px):** 6-column grid; weekly tracker shrinks to icon + metric format.
- **Desktop (1025px+):** Full 12-column layout with split tracking panels (e.g., 8-column syllabus tracker + 4-column weekly execution agenda).

## Elevation & Depth

This design system avoids theatrical drop shadows, using crisp, low-intensity ambient elevations grounded by micro-borders.

### Elevation Hierarchy
- **Level 0 (Flat Canvas):** `#F8FAFC`. Used for global backgrounds and dashboard backplates.
- **Level 1 (Card & Module Layer):** `#FFFFFF` background with a crisp border (`1px solid #E2E8F0`) and an ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.04)`.
- **Level 2 (Active / Hover / Dropdown):** `#FFFFFF` with `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)` and border `#CBD5E1`.
- **Level 3 (Modals & Flying Inspect Panels):** `#FFFFFF` with `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.08)`.

### Dark Command Surfaces
The dark navigation sidebar (`#0F172A`) uses tone-on-tone depth: child sub-nav surfaces use `#1E293B`, with hover overlays set to `rgba(255, 255, 255, 0.04)`.

## Shapes

The design system employs **Soft (1)** geometry: 
- Base elements (cards, table headers, text inputs): `4px` (`0.25rem`).
- Large containers, modals, and metric scorecards: `8px` (`0.5rem`).
- Micro elements (status pills, progress pips, badge indicators): Fully rounded capsules (`9999px`) to create an immediate shape-distinction between containers and operational metadata.
